# STGFIP

An open testbed that generates labelled, standards-compliant spacecraft
telemetry with **cascading** fault injection. Eight subsystems are integrated
as one joint state under an explicit coupling operator **C**, so a fault
propagates along modelled physical paths rather than through assigned labels.
Cascade labels — including propagation latency and originating subsystem — are
*computed* by differencing each episode against a paired nominal run, not
authored by hand. Every sample is encoded through the ECSS-PUS / CCSDS stack.

This repository is the artifact for the paper *"STGFIP: An Open Testbed for
Generating Labelled, Standards-Compliant Spacecraft Telemetry with Cascading
Fault Injection"*.

## Quick start

```bash
pip install -r requirements.txt
python3 run_all.py
```

20 stages, about 12 minutes, roughly 1.5 GB of intermediates under `/tmp`.
Everything in `results/` is regenerated from scratch. See `HOWTO_RUN.md` for
per-stage control, expected console output and common errors.

## Reproducing each result in the paper

| Paper | Claim | Stage | Output |
|---|---|---|---|
| §V-A (Q1) | 250 CADUs / 2000 packets round-trip at the 16-bit bound | 6 | `results/results_conformance.json` |
| §V-B (Q2) | **C = 0** removes every cascade: 11/80 → 0/80 | 1–4 | console, stages 2 and 4 |
| §V-C | κ sensitivity (12/11/9) and 63 % censoring | 5 | `results/results_labels.json` |
| §V-D (Q3) | LOEO attribution 11/11, majority 0.455 | 18 | `results/results_rootcause.json` |
| §V-E (Q4) | Table 2 detectors at matched false-alarm budget | 11–14 | `results/results_final.json` |
| §V-F | Ablations A1 (**C** = 0), A2 (raw, −ϱ) | 15–17 | `results/results_final.json` |
| §III-A | Step size: 0.15 σ at h = 0.5 s | — | `results/results_stepsize.json` |

The headline contrast is visible without running the detectors: stage 2
prints `episodes that cascaded: 11 / 80` and stage 4, on an identical corpus
with **C** = 0 and the same seeds and faults, prints `0 / 80`.

## What is in `artifacts/`

Small, human-readable files, regenerated by stage 19.

| File | Contents |
|---|---|
| `splits.json` | the fixed 60/15/25 split, **by episode** (57/14/25), seed 3 |
| `channels.csv` | all 22 channels with subsystem and the specified σ⁰ constant |
| `fault_schedule.csv` | one row per episode: subsystem, target, type, onset, severity |
| `seeds.json` | corpus, split, bootstrap and model seeds |
| `sample_250.cadu` | 250 real CADUs — 256,000 B = 250 × 1024 |

The CADU stream is genuine Layer-3 output: 4-byte ASM `1ACFFC1D`, Reed–Solomon
(255,223) interleave 4, pseudo-randomised with
h(x) = x⁸+x⁷+x⁵+x³+1. Check it with any CCSDS decoder, or:

```python
from stgfip import ccsds
s = open("artifacts/sample_250.cadu", "rb").read()
print(sum(ccsds.decadu(s[i*1024:(i+1)*1024]) is not None for i in range(250)))
# 250
```

## Figure provenance

`figures/` holds the figures as published. Every one except Fig. 1 is produced
by `make_figs2.py` (stage 20) from the same runs that generate the tables;
Fig. 1 is drawn directly in TikZ in the paper source. No figure is
AI-generated and all are reproducible from this repository.

## Layout

```
run_all.py            driver — start here
gen_corpus.py         Layer 1: integrate the coupled dynamics (RK4, h = 1 s)
build_dataset.py      Layer 2: paired-trajectory differencing -> labels
features.py           rolling statistics, spectra, cross-correlation ϱ
prep_final.py         episode-level splits and feature matrices
exp_final.py          detectors, matched operating points, bootstrap CIs
exp_rootcause.py      leave-one-episode-out origin attribution
exp_conformance.py    CCSDS round-trip and bit-error-rate tests
stats_labels.py       κ sensitivity and censoring statistics
export_artifacts.py   writes artifacts/
make_figs2.py         figures
stgfip/
  batch.py            vectorised dynamics + observation map; the gate for C = 0
  models.py           orbit, eclipse, subsystem parameters
  faults.py           fault signatures (step, drift, soft, intermittent)
  ccsds.py            Space Packet, TM frame, RS(255,223), randomiser, CADU
  generate.py, sim.py single-episode reference implementation
```

## Scope and limitations

Stated plainly, as in the paper:

- **No validation against real flight telemetry.** This is the principal gap.
  The **C** = 0 experiment shows the coupling operator produces the cascades
  *in our model*, not that they resemble a real spacecraft's.
- All 96 episodes share one orbit, one β angle and one duty cycle — **no
  orbital diversity**.
- 27.7 % of samples are faulty, far above real rates, so precision and
  false-alarm figures are optimistic relative to flight.
- Protocol-layer faults are injectable but **not** carried into the label
  vector, so they are verified, not evaluated for detection.
- The decoder in `ccsds.py` is independent of the encoder but shares our
  reading of the standard; validation against an operational ground system
  remains outstanding.
